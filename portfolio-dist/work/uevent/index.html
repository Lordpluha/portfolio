uEvent

Event discovery and ticketing platform with organiser payouts

Open live demoSource

About this demo

Runs on fixture data — the NestJS API is not deployed. Checkout stops at a clearly labelled demo screen; no payment provider is wired in.

Overview

Event catalogue with format, tag, date and geo filters; event pages with galleries, attendees and comments; ticket purchase through Stripe Connect; organiser dashboards with wallet, revenue charts, promo codes and withdrawal requests.

Highlights

  • 22 pages across 23 routes in a Feature-Sliced Design layout, fully typed.
  • Two-sided marketplace: attendee purchase flow and organiser financial dashboard, including payouts.
  • Bilingual interface (English / Ukrainian) with locale-aware formatting.
