# Превью проектов — папка для ревью

Здесь лежат 16 проектов, подготовленных к статичному показу работодателю.
**Ничего не закоммичено и не запушено.** Это отдельная копия для твоего просмотра.

## Как посмотреть

```bash
cd portfolio-preview/preview
python3 -m http.server 8080
```

Открой <http://localhost:8080/> — это навигационная страница со всеми проектами,
скриншотами, стеком и вердиктом по каждому.

Отдельный проект: <http://localhost:8080/cabhub/> и т.д.

> Открывать `index.html` двойным кликом (`file://`) не стоит — часть проектов
> использует относительные пути и fetch, которые в `file://` не работают.

## Структура

```
preview/     16 готовых статичных сайтов + index.html (навигация)
reports/     подробный отчёт по каждому проекту (21 файл, включая fullstack-репозитории)
shots/       скриншоты рендера: 1440×900 и 390×844
```

## Как это проверялось

Каждое превью поднималось на локальном сервере **из подкаталога** (как оно будет
лежать на GitHub Pages) и открывалось в headless-Chromium на 1440×900 и 390×844.
Фиксировались ошибки консоли, неудачные запросы, битые изображения; скриншоты
просматривались глазами.

Все пути относительные — ни одного `/`-абсолютного, `file://` или `C:\`.
CDN-зависимости (jQuery, Google Fonts) вынесены в локальные файлы, поэтому
превью работают полностью автономно.

## Что дальше

Деплой на GitHub Pages и создание отдельных репозиториев — **не сделано**,
ждём твоего ревью. Отчёты в `reports/` содержат честный список оставшихся
дефектов по каждому проекту — стоит прочитать до публикации.
